## 📊 ESTRUCTURA

```
ANTES:
- Ciudad era CharField (texto simple)
- Todas las ciudades se mostraban en un combobox grande

AHORA:
- Provincia (nuevo modelo)
- Ciudad (relacionado a Provincia)
- Usuario tiene: provincia + ciudad (ambos ForeignKey)
- Combobox de ciudad se filtra automáticamente por provincia
```

## ⚠️ TROUBLESHOOTING

### Error: "No such table: usuarios_provincia"
```bash
python manage.py migrate
```

### Error: "No such column: usuarios_usuario.provincia_id"
```bash
python manage.py migrate
```

### Combobox de ciudades no se llena
1. Abre Developer Tools (F12)
2. Ve a Network
3. Selecciona una provincia y verifica que se hace la petición AJAX
4. Si ves error 404 → las rutas no están registradas (verifica urls.py)
5. Si ves error en la API → ejecuta las migraciones

### Provincias vacías
```bash
python setup_provincias_ciudades.py
```

## ✨ CÓMO FUNCIONA

1. **Usuario accede a /register/**
2. Ve combobox de Provincia (sin ciudades)
3. **Selecciona Provincia**
4. JavaScript dispara AJAX a `/api/ciudades-por-provincia/<id>/`
5. Servidor retorna JSON con ciudades de esa provincia
6. Combobox de Ciudad se llena dinámicamente
7. Usuario selecciona Ciudad
8. Completa registro
9. Se guarda: nombre, email, teléfono, **provincia**, **ciudad**
