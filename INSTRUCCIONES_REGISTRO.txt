Abre una terminal en la raíz del proyecto y ejecuta:

```bash

```

Esto hará:

2. ✓ Poblará las ciudades del Ecuador
3. ✓ Mostrará un resumen

```bash

```

```bash
python manage.py shell
```

## VERIFICACIÓN FINAL

### 1. Reinicia el servidor
```bash
# Detén: Ctrl+C
python manage.py runserver
```

### 2. Ve al formulario
Abre en el navegador: `http://localhost:8000/register/`

Deberías ver:
- ✓ Campo de Nombre
- ✓ Campo de Apellido
- ✓ Campo de Email
- ✓ **Campo de Teléfono** (nuevo)
- ✓ **Dropdown de Ciudades** (nuevo)
- ✓ Campo de Contraseña
- ✓ Campo de Confirmar Contraseña

### 3. Prueba el registro
- Completa todos los campos
- Selecciona una ciudad del dropdown
- Haz clic en "Register"
- Deberías ser redirigido a tu cuenta

### 4. Verifica en el admin
- Ve a `http://localhost:8000/admin/`
- Ve a Usuarios → Usuarios
- Haz clic en el usuario que acabas de crear
- Deberías ver:
  - Teléfono: el que ingresaste
  - Ciudad: la que seleccionaste

## 🐛 TROUBLESHOOTING

### Error: "No such table: usuarios_ciudad"
**Solución:**
```bash
python manage.py migrate
```

### Error: "No such column: usuarios_usuario.ciudad_id"
**Solución:**
```bash
python manage.py migrate
```

### El dropdown no muestra ciudades
**Solución:**
```bash
python setup_all_ciudades.py
# O:
python manage.py shell < setup_all_ciudades.py
```

### El formulario no se carga
**Solución:**
- Detén el servidor (Ctrl+C)
- Ejecuta: `python manage.py runserver`
- Abre el navegador
